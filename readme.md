# Wammo E-Commerce

> **Note:** This repository is a public UI showcase for an e-commerce platform designed in 2018. The main codebase is stored in a private repository.

## Login Screen

![Session](./img-readme/img-iniciar-sessao.png)

The `sessao.html` page handles user authentication for the Wammo website, combining login features with marketing elements.

* **Header & Navigation:** Features the brand logo, search bar, shopping cart icons, and key product categories.
* **Authentication Form:** Allows email/password login, persistent session toggles, and store card integration.
* **Perks Banner:** Displays membership benefits (e.g., free shipping, best price guarantee) to encourage user sign-ups.
* **Footer:** Customer support links, company details, accepted payment methods, and legal terms.

## Create Account Screen

![Create Account](./img-readme/img-criar-conta.png)

The `conta.html` page provides a clear user registration interface.

* **Registration Form:** Captures user details (first/last name, date of birth, email, password), loyalty program opt-in, and Terms & Conditions acceptance.
* **Main Navigation:** Category links for Products, Promotions, What's New, Services, Repairs, Events, and Stores.
* **Footer:** Full institutional footer with support desk links, social media channels, user feedback, and compliance information.

## Essential E-Commerce Features

Key features every robust e-commerce platform should implement:

* **User Authentication & Profiles:** Secure sign-up/login, address book management, order history, and wishlist.
* **Product Catalog & Search:** Category hierarchy, advanced filtering, sorting, and real-time search.
* **Shopping Cart & Checkout:** Persistent cart, coupon code application, tax/shipping calculation, and streamlined checkout flow.
* **Payment Gateway Integration:** Secure processing for credit cards, digital wallets, bank transfers, and local payment methods.
* **Order Tracking & Notifications:** Automated email/SMS updates on order status and shipment tracking.
* **Customer Support & Trust:** Live chat/helpdesk, clear return and refund policies, customer reviews, and SSL encryption.
